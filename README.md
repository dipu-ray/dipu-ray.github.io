## 👨‍💻 About

This is my personal portfolio website — built from scratch to showcase my skills, projects, and professional journey as a **Frontend Developer**. Every section, from the hero banner to the contact form, is handcrafted with a focus on clean UI, smooth interactions, and well-structured, maintainable code.

> 💡 The goal wasn't just to build a portfolio — it was to practice real-world frontend engineering: responsive layouts, accessibility, performance, and thoughtful UX.

## 🌐 Deployment

This project is deployed on **GitHub Pages**.

To deploy your own fork:

1. Go to your repository **Settings** on GitHub
2. Click on **Pages** in the left sidebar menu
3. Under **Build and deployment**, set the Source to **Deploy from a branch**
4. Choose your branch (usually `main`) and folder (usually `/root`)
5. Click **Save** — done! ✅

Your site will be live at `https://dipu-ray.github.io/`
